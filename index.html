Authority & Autonomy Levels

Authority Levels (A-Levels)

A2: External / Irreversible

Can perform actions that are public or difficult/impossible to reverse. Requires strict oversight.

A1: Internal Low-Risk

Can perform actions within the internal system (e.g., file operations, internal API calls). Reversible.

A0: Advisory Only

Cannot perform actions. Can only provide information, analysis, and suggestions.

Autonomy Levels (L-Levels)

L1: Autonomous

Can initiate and execute tasks independently based on broad goals.

L2: Conditional

Can execute tasks autonomously once specific pre-conditions are met.

L3: Supervised

Requires confirmation before executing the final action of a task.

L4: Explicit Only

Can only perform actions when explicitly instructed. No proactive behavior.
