   was enabled after encrypted S3 rollback verification.

   The migration took about 241 seconds and lint another 152 seconds. A minimal
   backport made validation honor the configured 1800-second budget. No test
   was skipped. The second candidate passed every gate, including startup.

   timeout left the initial fingerprint undefined, and the recovery branch

   superseded by the official 2026.9.5 package, whose budget logic already
   removes the two caps.

   refused continuation. The Gateway was stopped by the updater. No old-binary
   rollback was attempted. `update repair` also failed on a deferred session
   source-index prerequisite; no missing index was fabricated.

   Codex remained pending. A second standalone pass confirmed this was not
   solved by merely reloading the newly installed plugin.
6. Source inspection identified Codex's after-session inspection being blocked

## Durable changes and tests

`evidence/2026-09-19-openclaw-update/source/` contains the deployed source copies
and the exact one-off recovery program. The linked ledger worktree preserves
all unrelated dirty files in the original checkout.

The guarded updater now checks native owner, free disk, validated configuration,
RPC health, online Gateway/CLI version identity, exclusive lock and no active
native update. It normalizes target versions and accepts `--dry-run` as a check
alias. Apply requires a pinned target; later targets require explicit per-run
Doctor approval. It validates the exact S3 object, positive byte count, SHA-256
format, producer/encryption/remote-readback verdict and no-local-archive flag.
It emits honest recovery-required/unknown-runtime states on failure, captures
unexpected errors, checks native success JSON, preserves routing/auth/channel
fingerprints, and requires same-PID sustained health, online runtime version,
lint and the complete expected Telegram account set before success.

The backup producer additionally preserves deployment scripts/unit, agent
auth/model files, plugin package manifests and local plugin/skill sources.
SQLite copies remain consistent and RAM-only; archives remain encrypted S3-only.
Reinstallable node dependencies and old local backup directories are excluded.

The 28 fixture tests exercise the actual shell script with isolated fake external
commands: success, approved next version, no-op, dry-run, missing approval,
unknown owner, unavailable health/service, concurrent update/lock, low disk,
invalid config, dry-run refusal, malformed/failed backup, native nonzero exit,
native error JSON with zero exit, changed protected config, wrong Gateway
version, local-only status, lint errors, failed/missing channels, unexpected
command failure, unpinned target and malformed target. They do not simulate
an actual future OpenClaw release or prove that future releases are defect-free.
